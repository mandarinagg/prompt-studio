# Contribuir

1. Tomá un issue (o abrí uno) y asignátelo.
2. Rama: `feat/<n>-slug`, `fix/<n>-slug`, `docs/<n>-slug`, `spike/<n>-slug`.
3. Commits en imperativo, en inglés o español, referenciando el issue (`#12`).
4. PR con la plantilla; cumplí la Definition of Done (`docs/PM_ANALYSIS.md` §4).
5. Decisiones de arquitectura → ADR en `docs/adr/`.

Nunca subas fotos/videos personales, claves de API ni archivos `.env`.
